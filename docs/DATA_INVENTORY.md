references available during the documentation review

and what has merely been reported outside the repository. An external listing
is not proof that a file is currently available or that its contents,
checksum, licence, or suitability have been verified.

## Status vocabulary

- **Committed:** tracked in this repository and directly inspectable.
- **External runtime input:** intentionally not committed; repository
  documentation records how it is used, but current availability is not
  implied.
- **External reference, inspected:** supplied outside the repository and read
  for this documentation review; it is not an active repository authority.
- **External reference, unverified:** named by an external inventory or
  repository plan but not present in this repository; no content or
  availability claim is made here.

## Preservation rules

- Do not commit raw SAFE archives or machine-specific runtime roots.
- Do not duplicate a committed result as a manually maintained canonical
  source.
- Do not replace frozen results, manifests, configurations, or protocols in
  place. New governed analyses use new versioned files and preserve their
  predecessors.
- When an external input becomes active, record its owner/source, licence,
  exact version, checksum, access boundary, intended use, and verification
  date before analysis begins.
